This is a starter note. While `draft: true` is set, it stays hidden and the Notes link does not appear.

To publish your first note:

1. Copy this file and rename it, for example `spring-ai-first-steps.md`.
2. Change the title, summary and date.
3. Set `draft: false`, then write in Markdown below this line.

A **Notes** link appears in the header as soon as one note is published.
